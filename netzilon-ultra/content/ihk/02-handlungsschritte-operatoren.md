## Profi

### Die sechs Handlungsschritte (Berufsbild FiSi)
Die IHK-Prüfung und die Aufgaben sind an den Kernaufgaben des Berufs („Handlungsschritte“) ausgerichtet:
1. **Informieren und Beraten** von Kunden (Bedarf, Anforderungen, Lastenheft, Beratungsgespräch).
2. **Planen und Realisieren** (Konzepte, Netzplan, Ressourcen).
3. **Beurteilen marktgängiger IT-Systeme** und kundenspezifischer Lösungen (Nutzwertanalyse, Wirtschaftlichkeit, TCO).
4. **Entwickeln, Erstellen und Betreuen** von IT-Lösungen (Installation, Konfiguration, Tests).
5. **Durchführen und Dokumentieren qualitätssichernder Maßnahmen** (Tests, Abnahme, Dokumentation, Monitoring).
6. **Umsetzen, Integrieren und Prüfen** von Maßnahmen zur IT-Sicherheit und zum Datenschutz.

### Operatoren (Aufgabenverben) und was erwartet wird
| Operator | Erwartung | Beispiel Antwort |
|---|---|---|
| **Nennen / Angeben / Benennen** | Begriff oder kurze Aussage, **keine** Erklärung | „Hash, Salt“ |
| **Beschreiben** | Merkmale/Ablauf in eigenen Worten, sachlich | Schrittfolge |
| **Erläutern / Erklären** | Begriff + Zusammenhang + Beispiel oder Begründung | 2–3 Sätze |
| **Begründen** | Behauptung + **weil** + Argument | „…, weil …“ |
| **Vergleichen / Gegenüberstellen** | Gemeinsamkeiten und Unterschiede nach Kriterien (Tabelle) | |
| **Berechnen** | Formel, Einsetzen, Ergebnis **mit Einheit** | |
| **Bewerten / Beurteilen** | Kriterien, Pro/Contra, **eigenes Urteil mit Begründung** | |
| **Skizzieren / Zeichnen** | Diagramm mit Beschriftung | |
| **Ergänzen / Vervollständigen** | fehlende Teile in Vorgabe | |
| **Entscheiden** | eine Option wählen und begründen | |

### Punktelogik und Technik
- **Punkte = Anzahl geforderter Aussagen**. 4 Punkte, „Erläutern Sie“: etwa 4 Aussagen oder 2 Aussagen mit je Begründung.
- „Nennen Sie zwei …“ → genau zwei; mehr kann zu Abzug führen, wenn eine falsch ist.
- Bei **Berechnen** immer Rechenweg + Einheit. Folgefehler werden meist nicht doppelt bestraft.
- **Kontext nutzen**: Fachbegriffe in Bezug zur Fallsituation (Unternehmen, Standort, Anzahl Nutzer).
- Fehler-Analyse aus alten Prüfungen: Operator ignoriert, Einheit fehlt, Aufgabe nur halb beantwortet, Antwort allgemein statt fallbezogen, Subnetzmaske falsch notiert, Rechenfehler im Dualsystem.

### Handlungsschritte im Projekt
Analyse (Ist/Soll) → Planung → Entscheidung (Nutzwertanalyse) → Umsetzung → Test → Abnahme → Dokumentation → Übergabe/Schulung. Siehe `ihk-dokumentation-praesentation`.

## Einfach

Die Prüfer lesen hunderte Antworten. Sie haben einen **Lösungsschlüssel** mit Punkten pro Aussage. Deine Aufgabe: so schreiben, dass jede Aussage leicht erkennbar ist.

**Die Signalwörter (Operatoren):**
- **Nennen**: nur Stichwörter. Wie bei „Nenne zwei Haustiere“: Hund, Katze. Fertig.
- **Beschreiben**: Sag, wie es aussieht oder abläuft, Schritt für Schritt.
- **Erläutern**: Erkläre es, als würdest du es einem Kollegen sagen, mit Beispiel.
- **Begründen**: Schreibe das Wort „weil“ in deine Antwort.
- **Vergleichen**: Eine kleine Tabelle mit „Vorteil/Nachteil“ oder „A/B“.
- **Berechnen**: Formel hinschreiben, Zahlen einsetzen, Ergebnis mit Einheit (€, GB, Minuten).
- **Bewerten**: Sage klar: „Ich empfehle X, weil …“

**Tricks:**
1. Lies die Aufgabe zweimal und unterstreiche das Signalwort und die Zahl (z. B. „zwei“).
2. Pro Punkt eine Aussage. 3 Punkte = 3 Gedanken.
3. Beziehe dich auf die Firma aus der Aufgabe („…bei 50 Mitarbeitern…“).
4. Schreibe nie nur „ja/nein“.
5. Rechne nicht im Kopf. Rechenweg aufschreiben.
6. Am Ende kurz prüfen: Passt das Ergebnis? (Plausibilität: Ein PC kostet nicht 5 €.)

**Die 6 Handlungsschritte** sind wie die Kapitel einer Arbeit: Kunde beraten, planen, Geräte vergleichen, installieren, testen/dokumentieren, Sicherheit. Fast jede Prüfungsaufgabe passt in eines dieser sechs Fächer.

## Merksatz
- Nennen = kurz, Erläutern = mit Erklärung, Begründen = mit „weil“.
- Punkte zählen Aussagen, nicht Zeilen.
- Rechenweg + Einheit = Punkte.
- Fallbezug schlägt Allgemeinwissen.

## Prüfungsfalle
- „Nennen“ mit einem langen Aufsatz beantworten verschwendet Zeit, „Erläutern“ mit Stichwort verschenkt Punkte.
- Mehr als verlangte Antworten: Die ersten werden gewertet, falsche zählen negativ.
- Einheiten und Rundung beachten (Netto/Brutto, GB/GiB, Bit/Byte).
- Wenn „zwei Vorteile“ verlangt sind: nicht Vorteil und Nachteil mischen.
- Begründung fehlt = meist halbe Punktzahl.

## Grafik
### Aufgabe richtig bearbeiten
1. Prüfling: Operator und Anzahl markieren
2. Prüfling: Fallsituation lesen, Randbedingungen notieren
3. Prüfling -> Aufgabenblatt: Antwort mit Stichworten gliedern
4. Prüfling: Rechenweg und Einheit ergänzen
5. Prüfling: Plausibilität prüfen

## Spickzettel
- Nennen kurz, Beschreiben sachlich, Erläutern mit Erklärung, Begründen mit „weil“
- Vergleichen als Tabelle
- Berechnen: Formel, Zahlen, Einheit
- Punkte = Aussagen
- Genau so viele Antworten wie verlangt

## Zuordnen
### Operator und Erwartung
- Nennen => Stichwort ohne Erklärung
- Erläutern => Begriff mit Zusammenhang oder Beispiel
- Begründen => Aussage mit „weil“ und Argument
- Vergleichen => Gemeinsamkeiten und Unterschiede
- Berechnen => Formel, Rechenweg und Einheit
