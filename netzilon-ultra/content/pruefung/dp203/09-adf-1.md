## Quiz

? pipeline1 (Data Factory) soll jeden Tag um 2 Uhr laufen. Wird der Trigger angehalten und neu gestartet, soll die nächste Ausführung wieder um 2 Uhr erfolgen (keine Nachholläufe). Welchen Trigger erstellen Sie?
* Zeitplantrigger (Schedule)
- Trigger für rollierende Fenster (Tumbling Window)
- Speicherereignistrigger
- benutzerdefinierter Ereignistrigger
! Ein Zeitplantrigger startet einfach zur nächsten geplanten Zeit; ein Tumbling-Window-Trigger würde verpasste Fenster nachholen (Backfill).

@ DP-203 Frage 117

? Pipeline1 enthält „Gespeicherte Prozedur1“ und danach „Variable festlegen1“ (verbunden über eine Fehler-Abhängigkeit). Pipeline2 enthält „Pipeline ausführen1“ (ruft Pipeline1 auf) und danach „Variable festlegen1“. Sie starten Pipeline2, die gespeicherte Prozedur in Pipeline1 schlägt fehl. Welchen Status haben die Läufe?
* Pipeline1 und Pipeline2 waren erfolgreich.
- Pipeline1 und Pipeline2 sind fehlgeschlagen.
- Pipeline1 war erfolgreich, Pipeline2 ist fehlgeschlagen.
- Pipeline1 ist fehlgeschlagen, Pipeline2 war erfolgreich.
! Fehler-Abhängigkeit = Try-Catch: Schlägt Aktivität 1 fehl und die per „Bei Fehler“ verbundene Aktivität 2 gelingt, meldet die Pipeline Erfolg – und damit auch die aufrufende Pipeline2.

- ein Ressourcen-Tag

- eine Ausführungsgruppen-ID
* eine Anmerkung (Annotation)

@ DP-203 Frage 125

? Ein Data-Factory-Datenfluss liest eine CSV-Datei (Username, Comment, Date), wandelt Typen per abgeleiteter Spalte um und schreibt per Senke in einen dedizierten SQL-Pool. Alle gültigen Zeilen sollen geschrieben, Kürzungsfehler in Comment proaktiv vermieden und betroffene Zeilen in eine Datei im Blob Storage geschrieben werden. Welche ZWEI Aktionen?
* eine Senkentransformation hinzufügen, die die Zeilen in eine Datei in Blob Storage schreibt
* eine Transformation für bedingte Teilung (Conditional Split) hinzufügen, die die problematischen Zeilen abtrennt
- eine Filtertransformation hinzufügen, die problematische Zeilen herausfiltert
- eine Select-Transformation hinzufügen, die nur problematische Zeilen auswählt
! Conditional Split trennt z. B. `length(Comment) <= n` (GoodRows → Datenbank) von den übrigen Zeilen (BadRows → zweite Senke als CSV-Datei im Blob Storage). Ein Filter würde die Zeilen nur verwerfen.
@ DP-203 Frage 133

? Ein Speicherkonto und ein Synapse-Data-Warehouse liegen in der Region „UK South“. Blobdaten sollen per Data Factory ins Data Warehouse kopiert werden; die Daten müssen jederzeit in UK South bleiben, der Verwaltungsaufwand soll minimal sein. Welche Integration Runtime verwenden Sie?
* Azure Integration Runtime
- Azure-SSIS Integration Runtime
- selbstgehostete Integration Runtime
! Eine Azure IR mit fester Region (UK South) hält Datenbewegung in dieser Region und wird von Microsoft verwaltet. Die selbstgehostete IR ist für lokale/private Netze gedacht und muss selbst betrieben werden.

### DP-203 Frage 8 (Hotspot): ADF-Kopieraktivität – 10 kleine JSON-Dateien (gleiche Attribute, je Tochtergesellschaft) sollen in einen anderen Ordner, schnellstmögliche Abfragen im serverlosen SQL-Pool, Schema automatisch ableitbar. Einstellungen?
- Kopierverhalten (Copy behavior) => Merge files (Dateien zusammenführen; die Sammlung nennt „Preserve hierarchy“, Community: Merge files)
- Senkendateityp (Sink file type) => Parquet

### DP-203 Frage 16 (Hotspot): Parquet-Dateien sollen per Data-Factory-Kopieraktivität von Storage1 nach Storage2 (beide mit hierarchischem Namespace) kopiert werden – ohne Transformation, Ordnerstruktur beibehalten, möglichst schnell.
- Quell-Dataset-Typ => Binary (keine Transformation nötig → am schnellsten; die Sammlung nennt Parquet, Community und Dozent: Binary)
- Kopierverhalten der Kopieraktivität => PreserveHierarchy
