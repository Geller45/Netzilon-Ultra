## Profi

### SMB im Überblick
**SMB** (*Server Message Block*) ist das Windows-Protokoll für **Datei-, Drucker- und IPC-Zugriff**. Es läuft heute auf **TCP 445**. Es gibt mehrere **Dialekte**; Client und Server **verhandeln** beim Verbindungsaufbau den höchsten gemeinsamen.

| Dialekt | Eingeführt mit | Merkmale |
|---|---|---|
| **SMB 1.0 (CIFS)** | NT 4.0 / 2000 | Unsicher, geschwätzig, keine Verschlüsselung, **Legacy** |
| **SMB 2.0.2** | Vista / Server 2008 | Weniger Befehle, Pipelining, größere Puffer |
| **SMB 2.1** | Windows 7 / Server 2008 R2 | Large MTU, Leases |
| **SMB 3.0** | Windows 8 / Server 2012 | **Verschlüsselung** (AES-CCM), **Multichannel**, **Transparent Failover**, SMB Direct |
| **SMB 3.0.2** | 8.1 / Server 2012 R2 | Optimierungen |
| **SMB 3.1.1** | Windows 10 / Server 2016 | **Pre-Authentication Integrity** (SHA-512), **AES-128-GCM**; Server 2022/11 auch **AES-256**, **SMB über QUIC** (Server 2022 Azure Edition, 2025) |

### Warum SMB1 abgeschaltet gehört
- **Keine Sicherheitsfunktionen**: keine Verschlüsselung, keine Integritätsprüfung → **Man-in-the-Middle**.
- **Angriffe**: **EternalBlue** (Patch **MS17-010**) nutzte eine SMB1-Lücke; **WannaCry** und **NotPetya** (2017) verbreiteten sich damit.
- **Schlechtes Zusammenspiel**: benötigt NetBIOS/Computer Browser; sehr viel Broadcast.
- Microsoft: SMB1-Client und -Server sind seit **Windows 10 1709 / Server 2019** nicht mehr installiert und in neuen Systemen **standardmäßig deaktiviert**.

### Wo SMB1 heute noch auftaucht
Alte **NAS-Geräte**, **Scanner/Kopierer (Scan-to-Folder)**, Messgeräte, Windows XP/2003-Systeme, alte **Samba-Konfigurationen** (`min protocol = NT1`), Steuerungen von Maschinen.

### Erkennen und Abschalten
1. **Audit einschalten** (Server): `Set-SmbServerConfiguration -AuditSmb1Access $true` → Ereignis **3000** im Log *Microsoft-Windows-SMBServer/Audit* zeigt, **wer** noch SMB1 nutzt.
2. **Client prüfen**: Wenn auf einem Windows-Client SMB1 nötig ist, ist meist das **Gerät** falsch (Firmware-Update, Scan-Protokoll auf SMB2/3 umstellen).
3. **Abschalten**: Server-Komponente aus, Client-Komponente entfernen (per **GPO** für alle).
4. **Verifizieren**: `Get-SmbServerConfiguration`, Tests mit dem alten Gerät.

### Weitere SMB-Härtung
| Maßnahme | Wirkung |
|---|---|
| **SMB-Signierung** erzwingen | Schützt vor Manipulation und Relay-Angriffen (NTLM-Relay) |
| **SMB-Verschlüsselung** (`EncryptData`) | Vertraulichkeit im Netz (SMB 3) |
| **Gastzugriff verbieten** (*Insecure guest logons*) | Verhindert anonymen/unsicheren Zugriff (in neuen Windows-Versionen standardmäßig aus) |
| **Port 445 nicht ins Internet** | Firewall-Regel am Perimeter; Nutzung über VPN oder **SMB über QUIC** |
| **Null Sessions** verbieten | Kein anonymer Zugriff auf Listen/IPC$ |

## Lab
**Maschinen**: **SRV01** (Dateiserver), **CL01** (Client), **DC01** (GPO).

### GUI
1. **SRV01**: PowerShell (Admin) → SMB1-Status prüfen: `Get-SmbServerConfiguration | Select EnableSMB1Protocol`.
2. **SRV01**: Server-Manager → Verwalten → Rollen und Features entfernen → Feature **„SMB 1.0/CIFS-Dateifreigabeunterstützung“** abwählen (falls vorhanden).
3. **CL01**: Systemsteuerung → Programme → Windows-Features aktivieren/deaktivieren → **„SMB 1.0/CIFS-Dateifreigabeunterstützung“** ausgeschaltet lassen.
4. **DC01**: GPMC → GPO „Sicherheit – SMB“ → Computerkonfiguration → Administrative Vorlagen → Netzwerk → **Lanman-Server** → „SMB 1.0-Server konfigurieren“ → Deaktiviert; **Lanman-Arbeitsstation**: „Unsichere Gastanmeldungen aktivieren“ → Deaktiviert.
5. **DC01**: GPO verknüpfen → **CL01, SRV01**: `gpupdate /force`.

### PowerShell
```powershell
# Auf SRV01 – SMB1 prüfen, auditieren, abschalten
Get-SmbServerConfiguration | Select-Object EnableSMB1Protocol, EnableSMB2Protocol, RequireSecuritySignature, EncryptData
Set-SmbServerConfiguration -AuditSmb1Access $true -Force
Get-WinEvent -LogName "Microsoft-Windows-SMBServer/Audit" -MaxEvents 20 | Where-Object Id -eq 3000
Set-SmbServerConfiguration -EnableSMB1Protocol $false -Force
Disable-WindowsOptionalFeature -Online -FeatureName SMB1Protocol -NoRestart

# Signierung und Verschlüsselung erzwingen
Set-SmbServerConfiguration -RequireSecuritySignature $true -EncryptData $true -Force

# Auf CL01 – welcher Dialekt wird genutzt?
Get-SmbConnection | Select-Object ServerName, ShareName, Dialect, Encrypted, Signed
```

## Befehle
- `Get-SmbServerConfiguration` – Server-Einstellungen (SMB1/2/3, Signierung, Verschlüsselung)
- `Set-SmbServerConfiguration -EnableSMB1Protocol $false` – SMB1 im Server abschalten
- `Get-SmbConnection` – Aktive Verbindungen mit Dialekt
- `Get-SmbSession` – Sitzungen auf dem Server
- `Get-SmbClientConfiguration` – Client-Einstellungen
- `Get-WindowsOptionalFeature -Online -FeatureName SMB1Protocol` – SMB1-Feature-Status

## Einfach

**SMB** ist die **Sprache**, in der Windows-Rechner Dateien austauschen. Es gibt sie in **Versionen**, wie Handys: SMB1 ist das **alte Wählscheibentelefon**, SMB3 das **verschlüsselte Smartphone**.

Das Wählscheibentelefon (SMB1) hat einen Fehler: **Jeder im Flur kann mithören**, und man kann einem Anrufer **falsche Antworten** unterschieben. Ein Einbrecher hat damals so viele Häuser in kurzer Zeit „angerufen“, dass er ein ganzes Stadtviertel lahmlegen konnte (**WannaCry 2017**).

Trotzdem gibt es alte Geräte, die **nur** dieses Telefon können, zum Beispiel ein **Scanner** vom Hausmeister. Was macht man?
1. Erst **mithören lassen**, wer überhaupt noch das alte Telefon benutzt (**Audit**).
2. Dem Gerät ein **neues Telefon** besorgen (Firmware/Einstellung auf SMB2/3).
3. Das Wählscheibentelefon **abstellen**.

Und für alle Telefone gilt: Wer **verschlüsselt** (SMB 3) und **Unterschrift** (Signierung) nutzt, ist sicher vor Mithörern und Fälschern.

## Merksatz
- SMB1 = **unsicher, abgeschaltet seit Windows 10 1709/Server 2019**.
- **SMB 3.0** = erste Version mit **Verschlüsselung**, **SMB 3.1.1** = Pre-Auth-Integrity.
- **TCP 445** direkt, TCP 139 = NetBIOS.
- **MS17-010 = EternalBlue**.
- Erst **auditieren**, dann abschalten.

## Prüfungsfalle
- „SMB1 = CIFS“: CIFS war Microsofts SMB1-Dialekt, heute meint man **SMB2/3**.
- **Signierung ≠ Verschlüsselung**: Signierung schützt die **Integrität**, Verschlüsselung die **Vertraulichkeit**.
- Port **445 nie aus dem Internet** erreichbar machen.
- Abschalten **ohne Audit** kann Scanner, NAS oder Maschinen ausfallen lassen.
- SMB 2.x hat **keine** Verschlüsselung – die kommt erst mit SMB 3.

## Grafik
### Dialekt-Treppe
Eine Treppe von SMB1 unten bis SMB3.1.1 oben; auf jeder Stufe erscheint ein Schild (Verschlüsselung, Multichannel, QUIC). Die unterste Stufe wackelt und bricht weg.

### WannaCry-Wurm
Ein Netzwerk aus Rechnern; ein roter Wurm springt über offene SMB1-Ports von Rechner zu Rechner. Ein Schalter „SMB1 aus“ lässt den Wurm an geschlossenen Türen abprallen.
