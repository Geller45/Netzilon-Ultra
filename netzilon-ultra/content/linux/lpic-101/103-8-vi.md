## Profi

### Lernziel (Gewicht 3)
Dateien im Texteditor **vi/vim** bearbeiten: Modi, Navigation, Bearbeiten, Suchen/Ersetzen, Speichern/Beenden.

### Modi
- **Normalmodus** (Standard beim Start; Befehle), **Einfügemodus** (Text tippen), **Befehlszeilenmodus** (`:`), Visual-Modus (`v`). Zurück in den Normalmodus mit **Esc**.
- Einfügemodus betreten: `i` (vor Cursor), `a` (hinter Cursor), `I` (Zeilenanfang), `A` (Zeilenende), `o` (neue Zeile darunter), `O` (darüber).

### Navigation
`h j k l` (←↓↑→), `w` / `b` (Wort vor/zurück), `0` / `$` (Zeilenanfang/-ende), `gg` / `G` (Dateianfang/-ende), `:42` bzw. `42G` (Zeile 42), Strg+F/B (Seite).

### Bearbeiten
| Befehl | Wirkung |
|---|---|
| `x` | Zeichen löschen |
| `dd` / `dw` / `D` | Zeile / Wort / bis Zeilenende löschen (cut) |
| `yy` / `yw` | Zeile / Wort kopieren (yank) |
| `p` / `P` | einfügen nach/vor Cursor |
| `u` / Strg+R | rückgängig / wiederholen |
| `.` | letzte Änderung wiederholen |
| `r` / `R` / `cw` | ersetzen |
| `3dd`, `5yy` | mit Zahl-Präfix |

### Suchen, Ersetzen, Speichern
- `/muster` (vorwärts), `?muster` (rückwärts), `n` / `N` weiter. `:%s/alt/neu/g` (alle Zeilen), `:s/a/b/`, Zusatz `c` für Rückfrage.
- **`:w`** speichern, **`:q`** beenden, **`:wq`** / **`ZZ`** / `:x` speichern + beenden, **`:q!`** ohne Speichern beenden, `:w datei` speichern unter, `:set number`. Swap-Datei `.datei.swp` bei Absturz. Bei `crontab -e`, `visudo`, `vipw` startet oft vi.

## Einfach

Der Editor **vi** ist anders als Word, weil er **zwei Gesichter** hat. Stell dir einen Schalter vor: Im **Kommando-Modus** sind die Tasten **Befehle** (z. B. `dd` löscht eine Zeile), im **Eingabe-Modus** tippst du **Text**. Anfänger bleiben oft hängen, weil sie im Kommando-Modus tippen und sich wundern, dass lauter seltsame Dinge passieren.

Der Trick: Mit **`i`** (insert) kommst du in den Schreibmodus. Mit **Esc** kehrst du zurück zum Befehlsmodus. Dann gibst du `:wq` ein (write + quit) und drückst Enter: Du hast gespeichert und bist draußen. Willst du ohne Speichern raus, schreibst du `:q!` – das Ausrufezeichen heißt „ich meine es ernst“.

Bewegen kannst du dich mit `h j k l` (links, runter, hoch, rechts) – oder mit den Pfeiltasten. `gg` springt an den Anfang, `G` ans Ende.

Zum **Ausschneiden, Kopieren, Einfügen** gibt es drei Wörter: `dd` (delete: Zeile ausschneiden), `yy` (yank: Zeile kopieren), `p` (paste: einfügen). Mit `u` machst du den letzten Schritt rückgängig – wie Strg+Z.

Zum **Suchen** tippst du `/wort` und Enter. Mit `n` springst du zum nächsten Treffer. Suchen und Ersetzen gelingt mit `:%s/alt/neu/g`.

## Merksatz
- **i = schreiben, Esc = zurück zu Befehlen.**
- **:wq speichern+raus, :q! raus ohne speichern.**
- **dd löscht Zeile, yy kopiert, p fügt ein, u macht rückgängig.**
- **/ sucht vorwärts, ? rückwärts.**
- **h j k l = ← ↓ ↑ →.**

## Prüfungsfalle
- Ohne Esc bleibt man im Einfügemodus; Befehle wie `dd` werden dann als Text getippt.
- `dd` **schneidet aus** (landet im Register, mit `p` einfügbar).
- `:q` verweigert bei Änderungen, `:q!` verwirft sie.
- `:wq` und `ZZ` speichern und beenden; `:x` speichert nur bei Änderung.
- `a` fügt **hinter** dem Cursor ein, `i` **davor**; `o` öffnet eine neue Zeile unter der aktuellen.
- `:%s/a/b/g` — `%` bedeutet alle Zeilen, ohne `%` nur die aktuelle.
- Wörter: `dw` löscht bis zum nächsten Wort.

## Grafik

### vi-Modi
1. Normalmodus: Start von vi, Tasten sind Befehle
2. Normalmodus -> Einfügemodus: Taste i
3. Einfügemodus: Text tippen
4. Einfügemodus -> Normalmodus: Esc
5. Normalmodus -> Befehlszeile: Doppelpunkt :wq
6. Befehlszeile -> Shell: Datei gespeichert, vi beendet

## Lab
**Maschine**: debian01.
```bash
# auf debian01
vi ~/test.txt
#   i  -> Text tippen -> Esc
#   yy p   (Zeile duplizieren)
#   /text  n  (suchen)
#   :%s/alt/neu/g
#   :wq
vimtutor        # interaktive Einführung
```

## Befehle
- `vi datei` – Datei öffnen
- `i` / `a` / `o` – Einfügemodus
- `Esc` – Normalmodus
- `dd` / `yy` / `p` – löschen / kopieren / einfügen
- `u` – rückgängig
- `/wort` – suchen
- `:%s/a/b/g` – ersetzen
- `:wq` – speichern und beenden
- `:q!` – ohne Speichern beenden
- `vimtutor` – Lernprogramm

## Lücken
- Mit {Esc} verlässt man den Einfügemodus.
- {:q!} beendet vi ohne zu speichern.
- Mit {yy} kopiert man eine Zeile und fügt sie mit {p} ein.
